# Calculator-Js-Html-Css 
 
This is a simple calculator web application built with HTML, CSS, and JavaScript. 
 
## Usage 
 
To use the calculator, follow these steps: 
 
1. Clone or download the repository to your local machine. 
2. Open the `index.html` file in a web browser. 
3. The calculator interface will be displayed, showing the output area and various buttons for numbers and operators. 
4. Click on the number buttons to enter numbers. The entered numbers will be displayed in the output area. 
5. Use the operator buttons (+, -, *, /) to perform calculations. The first number entered will be used as the left operand, and the second number entered will be used as the right operand. 
6. Click on the equals button (=) to calculate the result and display it in the output area. 
7. To clear the output area, click on the AC button. 
8. To delete the last character entered, click on the DEL button.
